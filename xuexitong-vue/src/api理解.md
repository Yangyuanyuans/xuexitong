api是程序之间约定好的一种调用接口 可以说api就等于沟通的桥梁 
比如我们去餐厅点餐这个时候我可以看作使用api的程序，服务员就是api，
菜单就是api的说明文档告诉我们有哪些功能可以使用，
后厨就是提供服务的系统，我们不需要知道后厨怎么做，服务员会自己把菜端到我们面前（api不需要知道系统内部是如何工作的）。
用户/程序通过api按照规定的格式提出请求然后系统再通过api返回得到结果 
在技术世界里 api就是两个软件系统之间沟通的桥梁 
ai调用api和普通的区别在于ai用api链接的是ai大模型 调用接口需要按token计费
检查api
用curl 加需要检查的api的UTR地址 选着请求的方法，发送请求，查看返回的JSON，判断，是否联通，返回结果，查看报错信息
api调用
在终端里面用curl +URL 
实际上就是我们向URL发起请求带上该带的信息 ，对方服务器收到请求后处理请求（我们这边看不到如何处理），
对方服务器返回我们一段数据 一般是JSON，终端把他打印出来，程序就直接用上这段数据
前端使用api接口
在Vue项目中使用axios调用API，首先要引入axios库，填写接口对应的URL地址，通过method指定请求方式，例如GET或POST，
同时带上需要传递的参数。发送请求之后，后端服务器处理并返回数据，一般是JSON格式
后端调用api
后端可以提供接口：部署完后端后会暴露一个URL地址，供给前端使用
后端使用api：主动去找别人的URL发送请求访问服务
